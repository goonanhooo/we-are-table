# we are table. — PC·폰 함께하기

각자 Windows Unity 실행본으로 같은 Steam/Unity 방에 들어가 게임 장면을 봅니다. 한 테이블의 네 다리를 PC 키보드와 웹 폰으로 섞어 조작할 수 있습니다. 호스트 PC가 물리를 계산하고 다른 Unity PC에 동기화합니다. Unity 실행본 없이 보는 사람은 웹 관전 화면을 열 수 있습니다.

## 플레이

1. 호스트 PC에서 `start.ps1`로 웹 중계와 공개 HTTPS 터널을 켭니다. `http://127.0.0.1:4180/host`에 폰 QR과 웹 관전 링크가 나옵니다.
2. 각 PC에서 `we-are-table.exe`를 실행합니다. 호스트는 **함께하기 → 방 만들기**, 다른 PC는 **함께하기 → 친구 방에 참가**를 누르고 호스트의 PC 방 코드를 입력합니다. Steam이 있으면 Steam 방, 그렇지 않으면 Unity Relay 방을 사용합니다.
3. Unity 로비에서 PC 키보드로 조작할 다리를 고릅니다. 호스트는 **폰 QR**을 눌러 네 다리의 QR·코드를 볼 수 있습니다. 폰으로 조작할 사람은 자신의 폰에서 QR을 스캔합니다. PC 다리로 선택된 자리는 폰이 가져갈 수 없고, 폰이 쓰는 자리는 PC에서 선택할 수 없습니다. PC는 다리를 선택하지 않고 같은 게임을 보며 자신의 폰으로 조작해도 됩니다.
4. 호스트가 맵과 난이도를 정해 시작합니다. 각 Unity PC는 동기화된 게임 장면을 렌더링합니다. 비어 있는 다리는 호스트 PC의 키보드로 조작할 수 있습니다. 폰 그림 아래 네 색 버튼을 누르면 아직 비어 있는 다른 다리로 전환할 수 있습니다.
5. Unity 실행본 없이 화면만 보려면 공개 주소의 `/watch`에서 관전 코드를 입력합니다. 이 웹 관전은 호스트 게임 화면을 최대 960px 너비, 초당 최대 8장으로 보내며 오디오는 보내지 않습니다.

`시작하기`는 기존 싱글 게임입니다. 폰 화면에는 조작기만 표시됩니다. 다른 Unity PC의 화면은 웹 영상 복사가 아니라 기존 게임 네트워크가 동기화한 장면입니다.

아이폰에서는 QR의 **HTTPS 주소를 Safari에서 직접 열고** **자이로 켜기**를 누른 뒤 동작/방향 접근을 허용합니다. 방향 센서와 동작 센서 권한을 한 번의 버튼 입력으로 요청합니다. 화면에 **자이로 켜짐 · 수직보정 대기**와 센서 입력 횟수가 보이면 폰을 곧게 세우고 **지금이 수직이다 · 보정**을 누릅니다. 조작 중에는 초록색 상태 표시와 앞뒤·좌우 기울기, 전체 각도, 다리 회전 각도가 실시간으로 바뀝니다. 방향 센서가 없으면 동작 센서의 중력·회전 값으로 전환하며, 회전 값이 없을 때는 기울기만 조작된다고 화면에 표시합니다. 수직 기준을 다시 잡거나 **터치로 전환**할 수 있습니다. 신호가 없거나 끊기면 조작 화면에 원인을 확인할 상태가 표시됩니다. 방향 버튼, ＋/−, 하단의 능력 버튼을 사용할 수 있습니다. 기린·테니스·얼음·오징어가 게임에서 활성화되면 폰의 테이블 그림도 바뀝니다. ◉로 네 다리의 색 표시를 끄고 켤 수 있습니다. 그림은 실제 `Table.prefab`과 게임 재질로 Unity에서 뽑은 정적 이미지입니다.

폰 화면에서는 테이블 그림이 남는 높이에 맞춰 줄어듭니다. 세로 568px 이상의 작은 화면에서도 터치 조작, 수직보정 대기, 자이로 조작 상태의 버튼을 한 화면에 표시하도록 맞췄습니다.

원본 다리 물리는 수직축 회전과 한 축 기울기의 두 관절로 구성되어 있습니다. 폰을 세운 상태에서 비틀면 수직축 회전이 동작합니다. 기울어진 상태에서는 해당 관절이 기울기 방향을 정하는 데 쓰입니다. 다리 자체의 길이축을 독립적으로 비트는 세 번째 관절은 현재 원본 구조에 없어 구현되지 않았습니다.

## 구성과 실행

Node.js 22 이상과 `cloudflared`가 필요합니다. ZIP을 푼 뒤 `npm install`을 실행하고, `cloudflared`를 PATH에 두거나 `CLOUDFLARED` 환경 변수에 실행 파일 경로를 지정하세요. 호스트 PC에서 `start.ps1`을 실행하면 중계와 터널이 함께 켜집니다. 중계만 켜려면 `node server.mjs`, 터널만 켜려면 `node internet.mjs`를 실행합니다.

중계는 `127.0.0.1:4180`에만 열리고 임시 공개 주소는 Cloudflare Quick Tunnel이 제공합니다. 터널이나 중계를 다시 시작하면 공개 주소와 네 다리 코드 및 관전 코드가 바뀔 수 있습니다. 중계 재시작 시 호스트 전용 설정은 호스트 PC의 Unity `persistentDataPath`에 갱신되므로 호스트 게임을 다시 실행해야 합니다. 복사해서 다른 PC에 보낼 Unity 실행본 폴더에는 호스트 설정 파일을 넣지 않습니다. 지속적인 공개 주소와 상시 서버가 필요하면 고정 터널 또는 별도 서버를 준비해야 합니다.

원본 프로젝트의 `Assets/Scripts/PhoneControllerBridge.cs`, `NetLegLink.cs`, `NetLegLink.Lobby.cs`, `NetDebugPanel.cs`, `LevelSelect.cs`, `TableInput.cs`, `ArtLegController.cs`, `KeyTutorial.PowerPractice.cs`가 함께 동작합니다. 다른 PC에서 원본 Unity 프로젝트를 열 경우 `unity/`의 스크립트와 `BuildPhoneControllerPlayer.cs`를 같은 위치로 복사하고 Unity 6000.3.17f1에서 빌드합니다. 프로젝트 경로가 다르면 `UNITY_PROJECT` 환경 변수로 중계에 알려줍니다.

## 검사

```powershell
node --test tests/*.test.mjs
node tests/internet.mjs
```

테스트는 폰과 PC 다리 예약의 상호 배제, 빈 다리로 전환, 관전자 인증 및 화면 전달, 입력과 자이로 회전 신호, 연결 해제와 재접속을 검사합니다. 실제 서로 다른 장소의 Unity PC 여러 대와 폰을 동시에 사용한 플레이 검사는 별도로 필요합니다.
