# WE ARE TABLE — 싱글 여정 웹 버전

[현재 구현·검증 상태](../../STATUS.md)

원본의 현재 본편 진행을 분석해 Three.js + Rapier 3D로 재구성한 로컬 브라우저 게임입니다.

## 실행

```powershell
node serve.mjs
```

http://127.0.0.1:4173/ 에서 **처음부터 시작**을 선택하세요. 기존 평지 화면이 열려 있다면 새로고침하세요. 엔진 파일은 dist/vendor/에 포함되어 있어 플레이에 패키지 설치나 CDN 연결이 필요하지 않습니다.

## 포함된 맵과 흐름

| 맵 | 진행 |
|---|---|
| 하얀 복도 | 의자 → 보행 → 트랩 개방 → 낙하 → 정글 |
| 정글 | 기린 앞 버튼 → 신축 능력 → 용암 협곡 → 동시 스위치 2개 → 열린 구멍 |
| 동굴·눈사람 | 테니스공 → 첫 광차 → 역에서 환승 → 두 번째 광차 → 머리 조립 → 얼음 → 경사로 → 로켓 |
| 우주 | 우주오징어 → 무중력 분사 → 달의 인력권 → 착륙 |
| 달 | 지구의 약 1/6 중력 → 집에 도착 → 부엌 입장 |
| 따뜻한 부엌 | 네 발의 실제 자리 감지 → 여섯 장면·82초 엔딩 → 완주 저장 |
| 축구 연습 | 동적 공과 발의 충돌 → 득점·실점 → 3골 또는 3분 종료 |
| 경주 타임어택 | 카운트다운 → 순서대로 반환 게이트 → 결승 → 최고 기록 |
| 평지 실험실 | 모든 능력, 벽·공·발판에서 자유 연습 |

상단 **맵 선택**에서 어느 맵이든 시작할 수 있습니다. 본편은 복도에서 시작하면 엔딩까지 이어집니다. 중간 맵은 이전에 얻었어야 할 능력을 제공합니다. 마지막 체크포인트와 진행은 이 브라우저의 localStorage에 저장됩니다. 서버·계정·온라인 멀티는 사용하지 않습니다.

## 조작

| 다리 | 스윙 / 회전 | 능력 동작 / 해제 |
|---|---|---|
| 왼쪽 뒤 | W S / A D | E / Q |
| 오른쪽 뒤 | T G / F H | Y / R |
| 왼쪽 앞 | I K / J L | O / U |
| 오른쪽 앞 | ↑ ↓ / ← → | ] / P |

방향키 다리의 보조 키는 [ / ' / ; / Enter입니다.

- 2 기린: 0.7–4.9m로 다리를 신축. = / −는 네 다리 동시 신축.
- 3 테니스공: 발을 가까운 지형·광차·동적 물체에 붙이고 떼기.
- 4 얼음: 마찰 0.02로 실제 경사로에서 미끄러지기.
- 5 오징어: 각 다리 방향으로 12N의 분사 힘.
- Space: 목표 방향으로 싱글 보행 보조. 우주에서는 목표를 조준해 분사.
- C: 가까운 대상과 상호작용, 광차 탑승·하차, 스위치·부엌 자리 정돈, 시작된 연출 건너뛰기.
- 1: 바로 세우기. 위험하거나 광차 위일 때는 체크포인트 복구.
- F1: 마지막 체크포인트에서 재시작. 연습 맵은 처음 위치로 복귀.
- Esc: 일시정지. 드래그로 카메라 회전, 휠로 확대.

화면 버튼도 같은 동작을 지원하고 조작 패널을 접을 수 있습니다. 광차는 발의 실제 부착이 있어야 출발합니다. 눈사람은 동적 머리가 조립 영역에 들어와야 완성됩니다. 엔딩은 네 발의 실제 위치가 바닥 자리와 맞아야 시작합니다.

## 재구성 범위

원본 커밋 189a52b의 Progress.cs, CheckpointCatalog.cs, 각 Stage/능력/컷씬 스크립트와 8개 활성 플레이 씬을 분석했습니다. source-flow.json에 실제 스크립트 설정과 위치를 추출했습니다. 현재 Jungle 씬에 연결된 문 스위치는 2개입니다.

이 버전은 모든 활성 맵 진행을 완주할 수 있게 만든 싱글 프로토타입입니다. 지형·동선·NPC·집·로켓을 작은 웹용 지형과 코드 기반 3D 모델로 재구성했습니다. 원본 메시·텍스처·음악·음성·컷씬 전체를 그대로 옮긴 버전은 아닙니다. _Unused와 _Recovery의 과거 테스트 씬은 제외했습니다.

상판·다리의 치수와 질량, yaw → swing 관절, ±90° 스윙, 입력 해제 홀드, 360° 회전, 100Hz 물리를 유지합니다. 웹 엔진에 맞춰 관성·솔버를 조정했습니다. 싱글 보조는 모터와 함께 몸통에 이동 힘·균형 토크를 추가합니다. 보조 중에는 발 마찰을 0.45로 낮추고, 긴 기린 다리는 벌리는 안정 자세로 협곡을 건넙니다. 보조를 누르지 않으면 기존 네 다리 독립 물리 조작입니다. 네 다리 동시 신축과 자리 정돈에도 균형 보조를 적용합니다. 테니스공 모드에는 늘어난 다리 길이를 유지해 혼자 머리 들기 퍼즐을 풀 수 있도록 했습니다.

## 검사

```powershell
node tests/physics.mjs
node tests/journey.mjs
```

- 기본 물리 23개 통과: 독립 스윙·홀드·yaw·각도 제한, 실제 마찰 이동, 복구, 연속 회전, 25초 스트레스.
- 맵·능력·진행 40개 통과: 9개 맵 물리/Three.js 씬 구성, 실제 복도 보행·낙하, 실제 신축·협곡 횡단, 발 접촉 스위치, 광차 부착·운행, 동적 머리 잡기, 조립 영역 판정, 실제 얼음 경사로 이동, 로켓/우주/달/엔딩 연결, 저장 복구, 축구 득점, 경주 게이트 순서와 최고 기록.
- 본편 체크포인트 16개 모두 도달·저장 검사.
- 일부 진행 검사에는 플레이어·퍼즐 물체를 해당 위치에 배치하는 fixture를 사용했습니다. 모든 구간을 실제 키보드로 수동 완주한 검사는 아닙니다.
- 로컬 HTML·모듈·엔진의 HTTP 200 응답 확인. 실제 브라우저 캡처·UI 조작 검증은 브라우저 도구의 초기 탐색 연결 실패로 미확인입니다.

검사 기록: verification.json.
